# Lupa

Tipo: Equipo de aventuras
Coste: 100 po
Volumen: 0,2

Esta lente permite ver objetos pequeños de cerca. También es útil como sustituto del pedernal y el acero para encender fuego. Para encender un fuego con una lupa se necesita luz solar para enfocar, yesca para encender y unos 5 minutos para que el fuego se encienda. Una lupa otorga ventaja en cualquier prueba de habilidad realizada para evaluar o inspeccionar un objeto pequeño o muy detallado.
