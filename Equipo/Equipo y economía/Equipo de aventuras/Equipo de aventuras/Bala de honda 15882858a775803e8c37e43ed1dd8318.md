# Bala de honda

Tipo: Munición
Coste: 0,2 pc
Volumen: 0,2

Las balas de honda se usan con un arma que tiene la propiedad de munición para realizar un ataque a distancia. Cada vez que atacas con el arma, gastas munición. Sacar la munición de un carcaj, una caja u otro contenedor es parte del ataque (necesitas una mano libre para cargar un arma de una mano).
