# Característica

Todas las criaturas (personajes y monstruos) tienen seis habilidades que miden características físicas y mentales, como se muestra en la tabla de descripciones de habilidades.

| Característica | La característica mide… |
| --- | --- |
| Fuerza (FUE) | Potencia corporal, aptitud atlética y el grado en que puedes ejercer fuerza física bruta. |
| Destreza (DES) | La agilidad, los reflejos y el equilibrio. |
| Constitución (CON) | Salud, resistencia y fuerza vital. |
| Inteligencia (INT) | Agudeza mental, precisión de memoria y capacidad de razonar. |
| Sabiduría (SAB) | Cuán en sintonía estás con el mundo que te rodea y representa la perspicacia y la intuición. |
| Carisma (CAR) | Su capacidad para interactuar con los demás y puede representar un encanto o un mando. |

# **Puntuación de característica**

Cada habilidad tiene una puntuación que va del 1 al 20, aunque algunos monstruos pueden llegar a tener una puntuación de hasta 30. La puntuación representa la magnitud de una habilidad. La tabla de puntuaciones de habilidad resume lo que significan las puntuaciones.

| Puntuación | Significado |
| --- | --- |
| 1 | Este es el valor más bajo que puede alcanzar una puntuación normalmente. Si un efecto reduce una puntuación a 0, ese efecto explica lo que sucede. |
| 2-9 | Esto representa una capacidad débil. |
| 10-11 | Esto representa el promedio humano. |
| 12-19 | Esto representa una fuerte capacidad. |
| 20 | Este es el puntaje más alto que puede alcanzar un aventurero, a menos que una característica indique lo contrario. |
| 21-29 | Esto representa una capacidad extraordinaria. |
| 30 | Esta es la puntuación más alta que se puede alcanzar. |

# **Modificador de característica**

Cada habilidad tiene un modificador que aplicas siempre que realizas una tirada de D20 con esa
habilidad (explicado en [Pruebas](Pruebas%20D20%2014882858a77580619f74c37ad6601f51.md)). Un modificador de habilidad se deriva de su puntuación, como se muestra en la tabla de Modificadores de Habilidad.

| Puntuación | Modificador | Puntuación | Modificador |
| --- | --- | --- | --- |
| 1 | -5 | 16-17 | +3 |
| 2-3 | -4 | 18-19 | +4 |
| 4-5 | -3 | 20-21 | +5 |
| 6-7 | -2 | 22-23 | +6 |
| 8-9 | -1 | 24-25 | -7 |
| 10-11 | +0 | 26-27 | +8 |
| 12-13 | +1 | 28-29 | +9 |
| 14-15 | +2 | 30 | +10 |
