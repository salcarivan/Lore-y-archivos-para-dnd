# Componentes

Los componentes de un hechizo son requisitos físicos que el lanzador de hechizos debe cumplir para lanzar el hechizo. La descripción de cada hechizo indica si requiere componentes verbales (V), somáticos (S) o materiales (M). Si el lanzador de hechizos no puede proporcionar uno o más de los componentes de un hechizo, no puede lanzarlo.

# VERBAL (V)

Un componente verbal es el canto de palabras esotéricas que suenan como tonterías para los no iniciados. Las palabras deben pronunciarse con un tono de voz normal. Las palabras en sí no son la fuente del poder del hechizo; más bien, la combinación particular de sonidos, con un tono y una resonancia específicos, pone en movimiento los hilos de la magia. Por lo tanto, una criatura amordazada o en una zona de silencio mágico no puede lanzar un hechizo con un componente verbal.

## Creación de componentes verbales

Si quieres decir el componente verbal de un hechizo, puedes inventar las palabras. Independientemente de cómo las hagas, el objetivo es crear algo que sea fácil de decir y que no signifique nada en el mundo real. Considera este método: toma el nombre del hechizo, mantén solo una instancia de cada una de sus letras y reorganiza las letras restantes para formar palabras. Por ejemplo, reorganiza las letras del conjuro *Bola de fuego* para crear Fer Balo, Fira Belu, Balor Fie o Bef Lira

# SOMÁTICO (S)

Un componente somático es una gesticulación enérgica o un conjunto intrincado de gestos. El hechicero debe usar al menos una de sus manos para realizar estos movimientos.

# MATERIAL (M)

Un componente material es un material particular que se utiliza para lanzar un hechizo, como se especifica entre paréntesis en la entrada Componentes. Estos materiales no son consumidos por el hechizo a menos que la descripción del hechizo indique lo contrario. El lanzador del hechizo debe tener una mano libre para acceder a ellos, pero puede ser la misma mano que se utiliza para lanzar componentes somáticos, si los hay.

Si un hechizo no consume sus materiales y no especifica un coste para ellos, el lanzador de conjuros puede usar una Bolsa de componentes en lugar de proporcionar los materiales especificados en el hechizo, o puede sustituirla por un Foco de lanzamiento de conjuros si tiene una característica que permite esa sustitución. Para usar una Bolsa de componentes, debes tener una mano libre para alcanzarla, y para usar un Foco de lanzamiento de conjuros, debes sujetarlo a menos que su descripción diga lo contrario.
