# Tiempo de lanzamiento

La mayoría de los hechizos requieren la acción de [Tapizar](Tapizar%2014882858a77580e284ead2021c82ec33.md) para lanzarse, pero algunos hechizos requieren una Acción adicional, una Reacción o 1 minuto o más. La entrada de Tiempo de lanzamiento de un hechizo especifica cuál de estos es necesario.

# UN CONJURO POR TURNO

En un turno, puedes gastar el maná suficiente para lanzar un hechizo. Esta regla significa que no puedes, por ejemplo, lanzar un hechizo con un espacio de hechizo usando la acción de [Tapizar](Tapizar%2014882858a77580e284ead2021c82ec33.md) y otro que use una Acción adicional en el mismo turno.

# DISPARADORES DE REACCIÓN Y ACCIÓN ADICIONAL

Un hechizo que tiene un tiempo de lanzamiento de una Reacción se lanza en respuesta a un disparador que está definido en la entrada de Tiempo de lanzamiento del hechizo. Algunos hechizos que tienen un tiempo de lanzamiento de una Acción adicional también se lanzan en respuesta a un disparador definido en el hechizo.

# TIEMPOS DE LANZAMIENTOS MÁS LARGOS

Ciertos hechizos, incluido un hechizo lanzado como un Ritual, requieren más tiempo para lanzarse: minutos o incluso horas. Mientras lanzas un hechizo con un tiempo de lanzamiento de 1 minuto o más, debes realizar la acción de [Magia](Tapizar%2014882858a77580e284ead2021c82ec33.md) en cada uno de tus turnos y debes mantener la [Concentración](Concentraci%C3%B3n%20ae225ac34e8d45eaa1895be889d50718.md) mientras lo haces. Si tu [Concentración](Concentraci%C3%B3n%20ae225ac34e8d45eaa1895be889d50718.md) se interrumpe, el hechizo falla, pero no gastas un espacio de hechizo. Para lanzar el hechizo de nuevo, debes comenzar de nuevo.
