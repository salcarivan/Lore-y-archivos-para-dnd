# Domesticar

Característica asociada: Sabiduría

La habilidad de **Domesticar** refleja tu capacidad para comprender y trabajar con animales, ya sea entrenándolos, cuidándolos o estableciendo una relación de confianza con ellos. Con esta habilidad, puedes enseñarles trucos, instruirlos para que sigan órdenes simples, o incluso domar criaturas salvajes para que se comporten de manera dócil. También abarca conocimientos específicos
sobre el cuidado y manejo de distintas especies.

### Usos comunes

- **Entrenamiento de Animales:** Enseñar trucos o comportamientos específicos, como sentarse, buscar objetos o responder a señales.
- **Comandos Básicos:** Lograr que un animal siga órdenes simples, como quedarse quieto, avanzar o regresar.
- **Domar Criaturas Salvajes:** Establecer un vínculo con animales salvajes para calmarlos o domesticarlos.
- **Falconería:** Entrenar y manejar aves rapaces para cazar o transportar mensajes.
- **Equitación:** Dominar el arte de montar y controlar caballos u otras monturas.
- **Cuidado de Manadas:** Supervisar y guiar a grupos de animales, como ovejas, perros de caza o ganado.
- **Conocimiento de Especies:** Entender el comportamiento y las necesidades específicas de diversas criaturas, incluidas las exóticas como insectos.

### Ejemplo de uso

Tu grupo encuentra un caballo asustado que podría ser útil para continuar su viaje. Realizas una
prueba de *Domesticar* para calmar al animal y ganar su confianza. Si tienes éxito, el caballo se tranquiliza y puedes usarlo como montura. Si fallas, el caballo podría huir o volverse agresivo por el estrés.
