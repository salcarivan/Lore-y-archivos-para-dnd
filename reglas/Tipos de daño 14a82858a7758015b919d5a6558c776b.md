# Tipos de daño

Los ataques y otros efectos dañinos causan distintos tipos de daño. Los tipos de daño no tienen reglas propias, pero otras reglas, como la Resistencia, dependen de los tipos. La tabla de tipos de daño ofrece ejemplos para ayudar al DJ a asignar un tipo a un nuevo efecto.

| **Tipos de daño** | **Ejemplos** |
| --- | --- |
| Ácido | Líquidos corrosivos, enzimas digestivas |
| Contundente | Objetos contundentes, constricción, caída |
| Cortante | Garras, objetos cortantes |
| Eléctrico | Rayos |
| Fuego | Llamas, calor insoportable |
| Fuerza | Energía mágica pura |
| Frío | Agua helada, ráfagas heladas |
| Necrótico | Energía que drena la vida |
| Perforante | Colmillos, objetos punzantes |
| Psíquico | Energía que desgarra la mente |
| Radiante | Energía sagrada, radiación abrasadora |
| Sonido | Sonido conmocionante |
| Veneno | Gas tóxico, veneno |
