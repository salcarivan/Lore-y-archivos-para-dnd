# Tapizar

Cuando realizas la acción Tapizar, lanzas un hechizo que tiene un tiempo de lanzamiento de una acción o usas una característica o un objeto mágico que requiere una acción Mágica para activarse.

Si lanzas un hechizo que tiene un tiempo de lanzamiento de 1 minuto o más, debes realizar la acción de Magia en cada turno de ese lanzamiento y debes mantener la [Concentración](Concentraci%C3%B3n%20ae225ac34e8d45eaa1895be889d50718.md) mientras lo haces. Si tu [Concentración](Concentraci%C3%B3n%20ae225ac34e8d45eaa1895be889d50718.md) se interrumpe, el hechizo falla, pero no gastas el maná necesario para lanzarlo.
