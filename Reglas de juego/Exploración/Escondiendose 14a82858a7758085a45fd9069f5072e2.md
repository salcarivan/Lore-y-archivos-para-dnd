# Escondiendose

Los aventureros y los monstruos suelen esconderse, ya sea para espiarse entre ellos, burlar a un guardián o tender una emboscada. El Director de Juego decide cuándo las circunstancias son apropiadas para esconderse. Cuando intentas esconderte, realizas la acción de [Esconderse](../Acciones/Principales%20acciones/Esconderse%2014882858a7758040a0d4d28c94fd9b65.md).
