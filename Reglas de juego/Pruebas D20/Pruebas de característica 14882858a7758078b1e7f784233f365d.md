# Pruebas de característica

Una prueba de característica representa a una criatura que usa su talento y entrenamiento para intentar superar un desafío, como abrir a la fuerza una puerta atascada, abrir una cerradura, entretener a una multitud o descifrar una clave. El DJ y las reglas suelen exigir una prueba de habilidad cuando una criatura intenta algo que no sea un ataque que tenga posibilidades de fracasar significativamente. Cuando el resultado es incierto y narrativamente interesante, los dados determinan el resultado.

# MODIFICADOR DE HABILIDAD

Una prueba de habilidad recibe su nombre según el modificador de habilidad que utiliza: una prueba de Fuerza, una prueba de Inteligencia, etc. Se requieren diferentes pruebas de habilidad en diferentes situaciones, según qué habilidad sea la más relevante. Consulta la tabla de ejemplos de pruebas de habilidad para ver ejemplos del uso de cada prueba.

| Característica | Haz una prueba para … |
| --- | --- |
| Fuerza | Levantar, empujar, tirar o romper algo |
| Destreza | Moverse ágil, rápida o silenciosamente |
| Constitución | Lleva tu cuerpo más allá de los límites normales |
| Inteligencia | Razonar o recordar |
| Sabiduría | Observar cosas en el entorno o en el comportamiento de las criaturas. |
| Carisma | Influir, entretener o engañar |

# BONO DE COMPETENCIA

Añade tu Bonificación de Competencia a una prueba de característica cuando el DJ determine que una habilidad o competencia con una herramienta es relevante para la prueba y tú tienes esa competencia. Por ejemplo, si una regla se refiere a una prueba de Fuerza ([Acrobacia](../Habilidades/Caracter%C3%ADsticas%20generales/Acrobacias%2014882858a77580bf8f11ee2deceaef34.md) o [Atletismo](../Habilidades/Caracter%C3%ADsticas%20generales/Atletismo%2014882858a7758017adbeca10ada6a343.md)), puedes añadir tu Bonificación de Competencia a la prueba si tienes competencia en la habilidad de Acrobacia o Atletismo. Consulta “[Competencia](../Competencia%2014882858a7758035918cd50025925cfd.md)” para obtener más información sobre las competencias con habilidades y herramientas.

# CLASE DE DIFICULTAD (CD)

La clase de dificultad de una prueba de habilidad representa la dificultad de la tarea. Cuanto más difícil sea la tarea, mayor será su CD. Las reglas proporcionan CD para ciertas pruebas, pero el DJ las establece en última instancia. La tabla de clases de dificultad típicas presenta una variedad de CD posibles para las pruebas de habilidad.

| Dificultad de la tarea | CD |
| --- | --- |
| Muy fácil | 5 |
| Fácil | 10 |
| Medio | 15 |
| Difícil | 20 |
| Muy difícil | 25 |
| Casi imposible | 30 |

# OTRAS PRUEBAS DE CARACTERÍSTICA

## Pruebas pasivas

Una **prueba pasiva** no implica ninguna tirada de dados. Este tipo de prueba de habilidad puede representar un resultado promedio para una tarea realizada repetidamente, como buscar puertas secretas una y otra vez. O un DJ puede usarla para determinar en secreto si un PJ tiene éxito en
algo que el jugador no sabe que debe intentar hacer, como notar un monstruo escondido. El total de una prueba pasiva se denomina puntuación. Aquí se explica cómo determinar la puntuación pasiva de un personaje:

- 10 + todos los modificadores que normalmente se aplican a la prueba.
- Si el personaje tiene ventaja, suma 5. Si tiene desventaja, resta 5.

Así, por ejemplo, si un personaje de nivel 1 tiene un modificador de habilidad de SAB +2 y es competente en la habilidad de Percepción, tiene una puntuación de [Percepción](../Habilidades/Caracter%C3%ADsticas%20generales/Percepci%C3%B3n%2014882858a77580dfa2f3f3109c37ce89.md) pasiva de 14 (10 + 2 para el modificador de SAB + 2 para BC).

## Trabajo en equipo

A veces, dos o más criaturas trabajan juntas. En este caso, la criatura con el modificador de característica más alto es designada para liderar el esfuerzo. Esa criatura puede hacer una prueba de característica con [ventaja](Ventaja%20y%20desventaja%2014882858a77580c8bc9be5a56437acbb.md), lo que refleja la ayuda que le brindan las demás. En combate, una criatura solo puede brindar este tipo de asistencia realizando la acción [Ayudar](../Acciones/Principales%20acciones/Ayudar%20c8edf02094f14b3a8094c6217f11897f.md).

Una criatura solo puede brindar ayuda si tiene la capacidad para realizar la tarea. Por ejemplo, intentar abrir una cerradura requiere habilidad con [herramientas de ladrón](https://app.notion.com/p/Herramientas-de-ladr-n-cd27c6e393cc42ecbb4e4693bfb6938d?pvs=21), por lo que una criatura que carezca de esa habilidad no puede brindar ayuda con una tarea de abrir cerraduras. Además, una criatura puede brindar ayuda solo cuando su asistencia sea productiva. Enhebrar una aguja no
es más fácil con otro par de manos.

## Pruebas grupales

Cuando varios individuos intentan lograr algo como grupo, el DJ puede pedir una prueba de grupo. En este caso, los personajes que son hábiles en una tarea ayudan a cubrir a los que no lo son.

Para hacer una prueba de grupo, cada miembro del grupo realiza la prueba de habilidad por separado. Si al menos la mitad de los miembros tiene éxito (redondeando hacia arriba), todo el grupo tiene éxito. De lo contrario, el grupo falla.

Las pruebas de grupo no se realizan a menudo y son más útiles cuando todos los personajes tienen éxito o fallan como grupo. Por ejemplo, cuando los aventureros navegan por un pantano, el DJ puede pedir una prueba de grupo de SAB ([Supervivencia](../Habilidades/Caracter%C3%ADsticas%20generales/Supervivencia%2014882858a7758017b31fe00d5bcc29b9.md)) para ver si todo el grupo puede evitar arenas movedizas y sumideros. Si al menos la mitad del grupo tiene éxito, los personajes exitosos guían a sus compañeros fuera del peligro. De lo contrario, el grupo tropieza con un peligro.
