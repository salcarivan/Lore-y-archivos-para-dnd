# Descanso corto

Los aventureros necesitan descansar en algún momento, aunque sea para recuperar el aliento entre una acción y otra, curar heridas y prepararse para los peligros que se avecinan.

En este capítulo se define el corto período de descanso, algunas actividades básicas que puedes realizar mientras descansas y cómo montar un campamento para pasar la noche.

# TOMANDO UN DESCANSO CORTO

Un descanso corto es un período de inactividad, de al menos 1 hora de duración, en el que los personajes se sientan para realizar algunas tareas básicas, como comer, beber y curar heridas.

Durante un descanso corto, puedes gastar dados de vigor, curar tus heridas y consumir algunos suministros esenciales, pero cualquier descanso más intensivo requerirá que te calmes y montes un campamento para una estadía más prolongada.

## Actividades básicas

Durante un breve descanso, mientras recuperas el aliento, puedes realizar algunas actividades básicas, como las tareas de ejemplo que se enumeran aquí. Las tareas complicadas o prolongadas pueden requerir que primero montes un campamento.

### Recuperar vigor

Gastas una cantidad de [dado de vigor](../Da%C3%B1o%20y%20curaci%C3%B3n%2014882858a775803ca2adff1a49137f01.md) iguales a tu nivel más tu modificador de CON para recuperar el resultado de esta tirada.

Si la condición ensangrentado está [ensangrentado](https://app.notion.com/p/14d82858a77580dfa369e983173d3e02?pvs=21) está activa y has perdido la mitad de tu vigor, necesitarás usar un [kit de sanador](https://app.notion.com/p/Kit-de-sanador-15d5b42f7e3a4e4c9b7b5b6dbe7a5d64?pvs=21), un [kit de cirujano](https://app.notion.com/p/d21d48f983414753b945a212e0f2ca70?pvs=21) o un [kit de herborista](https://app.notion.com/p/Kit-de-herborista-14e82858a77580eab934c94a0e289ee8?pvs=21) para gastar los dados de vigor.

### Recuperar rasgos raciales o de clase

Algunas clases y razas recuperan poderes después de un breve descanso: el ki de monje, los espacios para hechizos de brujo, el arma de aliento de dracónido, etc. Consulta tu hoja de personaje para ver qué rasgos recuperas.

### Comer y beber

Puedes usar este tiempo para saciar tu hambre o sed.

Además, si sufres agotamiento causado por una o más de tus condiciones de supervivencia, puedes eliminarlas si esa condición ha mejorado lo suficiente.

Algunas de estas actividades de campamento pueden proporcionar beneficios adicionales y mejorar ciertas condiciones del personaje:

- **Comer:** si comes una comida caliente, curas 2 puntos de [hambre](../Exploraci%C3%B3n/Condiciones%20de%20supervivencia%2015a82858a77580a6b425f51417df48bd.md).
- **Beber:** si bebes un reconstituyente, curas 2 puntos de [sed](../Exploraci%C3%B3n/Condiciones%20de%20supervivencia%2015a82858a77580a6b425f51417df48bd.md).
- **Dormir:** si duermes sin interrupciones, curas 3 puntos de [fatiga](../Exploraci%C3%B3n/Condiciones%20de%20supervivencia%2015a82858a77580a6b425f51417df48bd.md).

### Tratar heridas

Si tienes alguna herida crítica, puedes tratarla si tienes suficientes recursos de primeros auxilios.

### Investigar

Pasas tu tiempo investigando, leyendo o investigando algo que esté a tu alcance, como un libro encriptado, un insecto desconocido, un monolito tallado de forma extraña o un objeto mágico no identificado.

### Estrés

La vida aventurera es una actividad estresante, pero un poco de tiempo libre junto a una fogata puede ayudarte a relajarte.

Las actividades de campamento pueden afectar a tus niveles de Estrés. Cuando realizas una prueba de actividad de campamento, lo siguiente también se aplica a tu resultado:

- **Éxito:** Curas una pequeña cantidad de Estrés.
- **Fracaso:** Obtienes una pequeña cantidad de Estrés.

# INSTALACIÓN DEL CAMPAMENTO

Si decides descansar durante un período prolongado de tiempo (o necesitas realizar algunas tareas complicadas), es hora de montar el campamento. Busca un lugar seguro, enciende una fogata, arma tus tiendas y asegura los animales, vehículos o carga.

Hay cinco pasos básicos que debes seguir cuando intentes montar un campamento:

1. **Montar el campamento:** realiza pruebas de Acampada para ver qué tan bien montas el campamento: cuantos más éxitos tengas, mejor será el lugar de acampada.
2. **Designar al vigía:** el vigía está a cargo de la defensa del campamento y vigila cualquier amenaza.
3. **Realizar actividades del campamento:** cada miembro del grupo (que no esté de guardia) puede realizar una actividad principal relacionada con el campamento además de cualquier otra actividad básica de descanso breve.
4. **Dormir:** intenta descansar un poco durante algunas horas.
5. **Recoger:** recoge el campamento y prepárate para seguir adelante.

## 1- Montar campamento

Para montar el campamento, cada miembro del grupo debe realizar una prueba de Acampar (una prueba de habilidad de Fuerza/Inteligencia/Sabiduría ([Supervivencia](../Habilidades/Caracter%C3%ADsticas%20generales/Supervivencia%2014882858a7758017b31fe00d5bcc29b9.md))) contra una CD objetivo (ver la tabla de CD de Acampar) mientras cada uno intenta ayudar a montar el campamento.

Cuantos más éxitos tenga el grupo, más minuciosamente preparará el campamento final, lo que hará que sea más fácil defenderlo, descansar y realizar otras actividades del campamento.

| **CD** | **Descripción de la prueba de acampada** |
| --- | --- |
| 10 | Es fácil encontrar tierra segura y seca / el clima está despejado. |
| 15 | Es necesario hacer esfuerzo para encontrar un lugar para acampar o si hay mal tiempo: lluvia, nieve ligera, niebla intensa, etc. |
| 20 | Es difícil encontrar un lugar seguro para acampar / el clima es terrible: fuertes lluvias, una tormenta feroz, un viento aullante. |

| **Fallos** | **Descripción de los resultados de la prueba de acampada** |
| --- | --- |
| 0 | Una acampada perfecta. Las pruebas de actividad son CD 5. |
| 1 | Una acampada decente con un defecto evidente. Las pruebas de actividad son CD 10. |
| 2 o más  | Un campamento de mala calidad que apenas cumple con su propósito. Las pruebas de actividad son de CD 15. |

### Equipo de acampada

Es difícil montar un campamento si dependes únicamente de la naturaleza para que te proporcione refugio y comodidad. Si no tienes ningún equipo de acampada adecuado (como un saco de dormir o una tienda de campaña), tira la tirada de Acampada con desventaja.

Algunos equipos, como una tienda de campaña para dos personas, pueden considerarse equipo de acampada para varias personas, si están dispuestas a compartirlo.

### Otras habilidades

Dependiendo de tu personaje y de tu trasfondo, puedes usar otra habilidad en lugar de [Supervivencia](../Habilidades/Caracter%C3%ADsticas%20generales/Supervivencia%2014882858a7758017b31fe00d5bcc29b9.md) (si es apropiado) al hacer tu prueba de Acampada. Por ejemplo:

- [Atletismo](../Habilidades/Caracter%C3%ADsticas%20generales/Atletismo%2014882858a7758017adbeca10ada6a343.md): ayudas moviendo algo pesado para despejar el espacio para el campamento.
- [Domesticar](../Habilidades/Caracter%C3%ADsticas%20generales/Domesticar%2014882858a77580f4b92ef9c92a64afcc.md): ayudas comprobando que el lugar no esté en el territorio de ningún animal salvaje peligroso.
- [Naturaleza](../Habilidades/Caracter%C3%ADsticas%20generales/Naturaleza%2014882858a77580ca837bd949e0d5714e.md): ayudas encontrando buena madera (y otro combustible natural) para la fogata.
- [Religión](../Habilidades/Caracter%C3%ADsticas%20generales/Religi%C3%B3n%2014882858a77580eab34ee76d890f406c.md): ayudas canalizando el poder divino de tu deidad para bendecir el lugar del campamento.

Se debe realizar al menos una prueba de Acampada usando la habilidad de Supervivencia, y cualquier habilidad alternativa solo puede ser utilizada por un miembro del grupo, así que elige quién tira qué habilidad.

## 2- El Vigía

Es un gran riesgo montar un campamento sin designar a alguien que vigile a los posibles intrusos. Un vigía está a cargo de la seguridad del campamento y vigila las posibles amenazas.

Si eres el vigía, realiza una prueba de Inteligencia ([Supervivencia](../Habilidades/Caracter%C3%ADsticas%20generales/Supervivencia%2014882858a7758017b31fe00d5bcc29b9.md)) para ver cómo proteges el campamento contra posibles peligros. Si tienes herramientas, equipo o magia que pueda ayudar (trampas, campanas, el hechizo Alarma), puedes realizar la prueba con ventaja.

**Éxito:** has detectado algunos puntos débiles en la defensa del campamento y los has asegurado.

**Fracaso:** has hecho un mal trabajo asegurando el campamento. Tienes desventaja en las pruebas de percepción contra posibles intrusos mientras acampas.

<aside>
<img src="https://app.notion.com/icons/die6_green.svg" alt="https://app.notion.com/icons/die6_green.svg" width="40px" />

**Clanda:** Yo vigilaré esta noche, le debo una a Viridian.

**DJ:** Todos ustedes hicieron un campamento decente, así que hagan una tirada de vigilancia contra CD 10 para establecer las defensas.

**Clanda:** Pondré algunos hechizos de Alarma alrededor del perímetro, eso debería ayudar.

**DJ:** Lo hace, hagan su tirada con ventaja.

**Clanda:** Sencillo... (tira 8 y 17) ...ven, nada se me va a escapar esta noche.

Ser el vigía requiere mucha concentración. Si eres el vigía, no puedes participar en ninguna de las actividades del campamento, salvo comer, beber y dormir.

## 3- Actividades de campamento

Mientras acampas, puedes realizar una actividad principal (además de las actividades básicas normales) antes de dormir. A continuación, se enumeran algunos ejemplos de actividades. Si alguna actividad no está incluida aquí, coméntala con tu DJ.

### Cocinar comida

Si sabe cocinar y cuenta con los suministros adecuados, puede preparar una comida para el grupo. Para ello, deberá utilizar una fogata y utensilios de cocina. Utilice un uso de sus [utensilios de cocina](https://app.notion.com/p/Utensilios-de-cocina-15582858a775809aa6c9fe26b481f7f7?pvs=21) para intentar una de las siguientes acciones:

- **Crear raciones:** cocinas a fuego lento y conservas algunos ingredientes frescos (normalmente carne o cereales) para crear 1d4+1 nuevas raciones de comida básica que se puedan conservar.
- **Ampliar las raciones**: reduces algunas raciones básicas hasta convertirlas en una comida sencilla, alimentando a dos personas por cada ración que cocinas. Si cocinas con éxito, todos los que coman ganan 1d4+1 puntos de golpe (máximo una vez al día).
- **Cocinar una comida caliente:** cocinas una comida caliente para todos, usando una ración (o sustituto de ración) por persona. Si cocinas con éxito, todos los que coman la comida caliente recuperan 1 dado de golpe gastado (máximo una vez al día).

Si cocinas con éxito una comida (raciones extendidas / comida caliente), curas una pequeña cantidad de [estrés](Estr%C3%A9s%20y%20trastornos%2014c82858a775802e93f6e32859be02fd.md) de todas las personas a las que sirves.

Antes de servir la comida, haz una prueba de Sabiduría ([Supervivencia](../Habilidades/Caracter%C3%ADsticas%20generales/Supervivencia%2014882858a7758017b31fe00d5bcc29b9.md)) para ver lo bien que has preparado todo. Las comidas se estropean al cabo de una hora y pierden sus propiedades restauradoras.

**Éxito:** La comida está bien preparada.

**Fracaso:** Has echado a perder la comida y has desperdiciado los ingredientes; nadie puede comer lo que has cocinado.

### Preparar bebidas

Si sabes preparar bebidas y tienes los suministros adecuados, puedes preparar algunas para el grupo. Para ello, necesitas una fogata y un equipo de elaboración de bebidas. Usa un uso de tus [suministros de cervecero](https://app.notion.com/p/Suministros-de-cervecero-17982858a77580319a18fbd87476b921?pvs=21) para probar una de las siguientes acciones:

- **Crear raciones:** destilas agua impura durante la noche para crear 1d4 + 1 nuevas raciones bebibles.
- **Elaborar un bálsamo:** con unas cuantas hierbas conviertes algunas raciones de agua básicas en una deliciosa bebida relajante (una ración por cada dos tragos). Todo aquel que beba un bálsamo fresco gana 1d4 + 1 puntos de golpe (máximo una vez al día).
- **Elaborar un reconstituyente:** conviertes algunas raciones de agua básicas en una sabrosa bebida caliente usando una ración por trago. Todo aquel que beba un reconstituyente fresco recupera 1 dado de golpe gastado (máximo una vez al día).

Antes de servir las bebidas, haz una prueba de Sabiduría ([Supervivencia](../Habilidades/Caracter%C3%ADsticas%20generales/Supervivencia%2014882858a7758017b31fe00d5bcc29b9.md)) para ver qué tan bien preparaste todo. Tus brebajes pierden sus propiedades restauradoras después de una hora.

Si preparas con éxito algunas bebidas (bálsamo / reconstituyente), curas una pequeña cantidad de [estrés](Estr%C3%A9s%20y%20trastornos%2014c82858a775802e93f6e32859be02fd.md) de todas las personas a las que sirves.

**Éxito:** Las bebidas están bien preparadas.

**Fracaso:** Echaste a perder la bebida y desperdiciaste los ingredientes; nadie puede soportar tus bebidas

### Tocar música

Si sabes tocar un instrumento, puedes intentar tocar algo de música para el grupo. Realiza una prueba de Destreza ([Interpretar](../Habilidades/Caracter%C3%ADsticas%20generales/Interpretar%2014882858a775809eb284c5133cd7bffe.md)) para ver qué tan bien tocas.

Si te desempeñas bien, curas una pequeña cantidad de [estrés](Estr%C3%A9s%20y%20trastornos%2014c82858a775802e93f6e32859be02fd.md) de todas las personas que te escuchan actuar.

**Éxito:** tocas bien e inspiras a uno de tus aliados. Elige a un miembro del grupo que no seas tú ni el vigía; ese personaje gana un punto de [suerte](../Pruebas%20D20/Suerte%2015282858a7758088b4cfe62a08d6421e.md).

**Fracaso:** cometiste un error vergonzoso.

### Contar una historia

A la gente le gusta escuchar una buena historia. Si eres competente en [Arcanismo](../Habilidades/Caracter%C3%ADsticas%20generales/Arcana%2014882858a775801e8405d641eaa6a5ce.md), [Sociedad](../Habilidades/Caracter%C3%ADsticas%20generales/Sociedad%2014882858a775809bb3bff3d796fdbbd0.md) o [Religión](../Habilidades/Caracter%C3%ADsticas%20generales/Religi%C3%B3n%2014882858a77580eab34ee76d890f406c.md) (o llevas un libro interesante), puedes intentar contar una historia cautivadora al grupo. Realiza una prueba de Carisma ([Interpretar](../Habilidades/Caracter%C3%ADsticas%20generales/Interpretar%2014882858a775809eb284c5133cd7bffe.md)).

Si te desempeñas bien, curas una pequeña cantidad de [estrés](Estr%C3%A9s%20y%20trastornos%2014c82858a775802e93f6e32859be02fd.md) de todas las personas que te escuchan actuar.

**Éxito:** Tu historia está bien contada e inspira a un aliado. Elige a un miembro del grupo que no seas tú ni el vigía; ese personaje gana un punto de [suerte](../Pruebas%20D20/Suerte%2015282858a7758088b4cfe62a08d6421e.md).

**Fracaso:** Cometiste un error vergonzoso.

### Reparar un objeto

Si eres competente con ciertas herramientas, puedes realizar reparaciones básicas en equipos dañados: afilar una espada desafilada, coser una túnica rota o martillar una armadura abollada. Puedes intentar quitar una muesca de un objeto con una prueba de [Herramienta](https://app.notion.com/p/Herramientas-14882858a7758059a90dd9bcd8f5b1b2?pvs=21) exitosa.

**Éxito:** quitas una muesca con éxito.

**Fracaso:** no pudiste hacer las reparaciones.

### Fabricar un objeto

Puedes dedicar tiempo a fabricar objetos sencillos (vendas, ungüentos, flechas) si tienes los materiales y las herramientas de fabricación adecuados. Realiza la tirada correspondiente a tu fabricación específica.

**Éxito:** has fabricado tu objeto con éxito.

**Fracaso:** no has podido fabricar el objeto.

### Jugar a un juego

Si tienes un juego de mesa y conoces las reglas, puedes jugar a un juego para relajarte. Cualquiera puede participar, siempre que no esté ocupado con otra actividad, pero al menos una de las personas que jueguen debe conocer las reglas.

Todos los que jueguen pueden hacer una prueba de habilidad de CAR ([Equipo de Juego](https://app.notion.com/p/Equipo-de-juego-15682858a77580ea8c91e280c4f174aa?pvs=21)); gana el que obtenga el resultado más alto.

Si ganas una partida, recuperas una cantidad moderada de [estrés](Estr%C3%A9s%20y%20trastornos%2014c82858a775802e93f6e32859be02fd.md). Si pierdes (o empatas), recuperas una cantidad menor.

**Ganador:** te sientes inspirado; obtienes un punto de [suerte](../Pruebas%20D20/Suerte%2015282858a7758088b4cfe62a08d6421e.md).

**Perdedor:** pierdes el juego.

### Relájate en soledad

Si prefieres pasar un tiempo solo (leyendo un libro, meditando, pintando), puedes hacerlo. Haz una prueba de SAB para ver si puedes relajarte.

Éxito: te sientes inspirado por tu aislamiento; gana un punto de inspiración.

Fracaso: no te pudiste relajar porque algo (o alguien) te estaba irritando demasiado.

## 4- Dormir un poco

A veces, la mejor forma de despejar la mente es desconectarla por un rato; el descanso suele ser la mejor medicina.

Cuando intentes dormir, haz una prueba de sueño (tirada de salvación de Constitución) contra la CD de Actividad de Acampada; si duermes en un saco de dormir o en una tienda de campaña, puedes hacer la tirada con ventaja.

Si duermes tranquilo, curas 3 puntos de [fatiga](../Exploraci%C3%B3n/Condiciones%20de%20supervivencia%2015a82858a77580a6b425f51417df48bd.md).

Si duermes sin interrupciones, recuperas una gran cantidad de [estrés](Estr%C3%A9s%20y%20trastornos%2014c82858a775802e93f6e32859be02fd.md). Si tu sueño es agitado, interrumpido o interrumpido por un intruso, recuperas una cantidad moderada de estrés.

**Éxito:** tu sueño no fue interrumpido. Recuperas 1 dado de golpe gastado (máximo una vez al día).

**Fallo:** no pudiste dormir bien y te despertaste cansado.

### Trance

Algunas razas no duermen como otras, sino que caen en un estado meditativo conocido como trance. En este estado, tu personaje está semiconsciente y solo parcialmente consciente de lo que sucede a su alrededor.

Mientras estás en trance, tienes desventaja en todas las tiradas de [Percepción](../Habilidades/Caracter%C3%ADsticas%20generales/Percepci%C3%B3n%2014882858a77580dfa2f3f3109c37ce89.md). Sin embargo, puedes realizar tus pruebas de sueño de forma normal.

### Usar armadura

La armadura, aunque es excelente para la defensa, no es una prenda cómoda para dormir. Si decides dejarte la armadura puesta mientras duermes, debes realizar la prueba de sueño con desventaja.

### El vigía

Mientras el vigía esté de guardia, puede realizar una prueba de sueño; simplemente supongamos que encuentra algo de tiempo para echarse una siesta rápida mientras los demás miembros del grupo siguen despiertos.

Sin embargo, el vigía realiza su prueba de sueño con desventaja; es difícil sentirse completamente descansado después de una noche de guardia.

## 5- Empacando

Cuando decidas seguir adelante, es hora de desarmar el campamento: apaga la fogata, ponte el equipo y regresa a la aventura. Esto puede llevar un poco de tiempo, según el tamaño y la permanencia de tu campamento.

# ¡EMBOSCADA!

Una cálida fogata y el olor de una deliciosa comida caliente pueden atraer la atención en la oscuridad de la naturaleza, desde crueles bandidos hasta osos hambrientos y cultistas sedientos de sangre. Si bajas la guardia, es posible que tanto tu sueño como tu vida se vean sorprendentemente truncados.

Si se acerca un intruso, el vigía realiza una prueba de Sabiduría (Percepción) contra el Sigilo del intruso:

**Éxito:** el vigía puede detectar a los intrusos y, si así lo deciden, despertar al grupo con tiempo suficiente para que la gente se ponga una armadura ligera.

**Fracaso:** el vigía (y el resto del grupo) son tomados por sorpresa.

## Falsas alertas

En la oscuridad, es fácil preocuparse por cada movimiento en las sombras y cada ruido distante: una ramita quebrada, un aullido lejano, un susurro en el viento.

En ocasiones, el DM puede pedir al vigía que haga una tirada de Sabiduría ([Percepción](../Habilidades/Caracter%C3%ADsticas%20generales/Percepci%C3%B3n%2014882858a77580dfa2f3f3109c37ce89.md)) para detectar una falsa alarma:

**Éxito:** El vigía se da cuenta de que es solo una falsa alarma y no despierta al grupo.

**Fracaso:** El vigía piensa que se acerca el peligro y despierta al grupo innecesariamente. Su sueño se ve perturbado durante el resto de la noche.
