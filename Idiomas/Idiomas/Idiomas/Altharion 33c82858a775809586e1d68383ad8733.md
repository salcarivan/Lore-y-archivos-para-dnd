# Altharion

Disponibilidad: 28
Dificultad: 48
Nombre alfabeto: Élfico de Hilo Fino
Familia: Lengua Silvana
Rama: Rama Élfica

**Cómo suena:** Preciso, musical y con vocal final casi siempre alargada. Las palabras son largas y cada sílaba tiene peso exacto. Escucharlo se describe como oír una composición ensayada, nunca improvisada.

**Alfabeto:** El Élfico de Hilo Fino usa trazos delgados y altos con conexiones horizontales frecuentes, como una melodía escrita. Comparten este sistema base las tres lenguas élficas, aunque con ornamentación y formalidad distintas. Escrito de izquierda a derecha en líneas horizontales sobre pergamino o madera pulida.

**Hablantes principales:** Altos elfos, academias del Consorcio Luminar, diplomáticos de ciudades-estado refinadas.

**Uso:** Literatura, magia formal, diplomacia entre ciudades-estado, archivo de historia y lore. Lengua de prestigo intelectual en gran parte de Vhaldros.
