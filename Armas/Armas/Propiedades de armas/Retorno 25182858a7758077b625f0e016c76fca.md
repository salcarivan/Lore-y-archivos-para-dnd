# Retorno

Armas diseñadas para volver a la mano del usuario tras ser lanzadas. Después de lanzar el arma, **puedes usar una acción adicional** para que vuelva a tu mano. Si eres competente con el arma, la recuperación es automática al usar la acción adicional. **Condición importante:** Debes recuperarla antes del final de tu **siguiente turno** o falla en regresar
