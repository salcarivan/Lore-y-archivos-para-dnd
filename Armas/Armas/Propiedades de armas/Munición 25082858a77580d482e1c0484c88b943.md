# Munición

Puedes usar un arma con la propiedad munición para hacer un ataque a distancia solo si tienes munición para disparar. En lugar de rastrear cada disparo individual, toma un d12: este es tu *Dado de Munición*. Tíralo cada vez que dispares: si sacas 1 o 2, el dado se reduce un tamaño.

**Progresión del Dado de Munición:** d12 → d10 → d8 → d6 → d4 → 1 pieza

Si estás en tu última pieza de munición y la usas, ¡se acabó! Retírala de tu inventario.
