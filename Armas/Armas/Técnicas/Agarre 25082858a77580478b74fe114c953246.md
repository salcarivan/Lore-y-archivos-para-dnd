# Agarre

Tipo: Básica
Cúando: Impactas el ataque pero no realizas daño

El objetivo debe superar una tirada de salvación de FUE o DES (elige cuál), o tiene la condición de [Agarrado](https://www.notion.so/14882858a77580a5aadfdef99125924c?pvs=21). Solo posible si el objetivo no es más de un tamaño mayor que tú. Requiere mano libre para mantener el agarre
