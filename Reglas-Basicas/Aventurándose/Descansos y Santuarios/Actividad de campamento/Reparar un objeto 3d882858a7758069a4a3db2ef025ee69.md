# Reparar un objeto

¿Que representa?: Arreglar equipo dañado
¿Necesitas equipo?: Herramientas de artesano

Si tienes competencia con ciertas herramientas, puedes realizar reparaciones básicas en equipo dañado: afilar una espada mellada, remendar una túnica rasgada o enderezar a martillazos una armadura abollada. Puedes intentar eliminar una muesca de un objeto mediante una prueba de Inteligencia (Mecánica) exitosa.

Éxito: Logras eliminar una muesca.

Fallo: No consigues realizar las reparaciones.
