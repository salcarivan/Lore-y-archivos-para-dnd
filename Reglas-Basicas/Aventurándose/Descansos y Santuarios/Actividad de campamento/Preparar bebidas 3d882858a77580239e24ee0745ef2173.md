# Preparar bebidas

¿Que representa?: Elaborar algo para beber esa noche
¿Necesitas equipo?: Suministros de cervero

Si sabes preparar bebidas y cuentas con el equipo adecuado, puedes elaborar algunas para el grupo. Esto requiere una hoguera y un equipo de elaboración de bebidas. Consume un uso de tus suministros de elaboración para intentar una de las siguientes acciones:

- **Crear raciones:** Destilas agua impura durante la noche para crear 1d4 + 1 raciones nuevas y aptas para el consumo.
- **Preparar un bálsamo:** Con unas pocas hierbas, transformas raciones de agua básica en una bebida deliciosa y reconfortante (una ración por cada dos bebidas). Quien beba un bálsamo recién preparado recupera 1d4 + 1 puntos de golpe (máximo una vez al día).
- **Preparar un reconstituyente:** Transformas raciones de agua básica en una bebida caliente y sabrosa, utilizando una ración por bebida. Quien beba un reconstituyente recién preparado recupera 1 dado de golpe gastado (máximo una vez al día).

Antes de servir las bebidas, realiza una prueba de Sabiduría (Supervivencia) para determinar qué tan bien has preparado todo. Tus bebidas pierden sus propiedades reconstituyentes al cabo de una hora.

**Éxito:** Las bebidas están bien preparadas.

**Fallo:** Arruinas la preparación y desperdicias los ingredientes; nadie es capaz de beber lo que has preparado.

**Recuperación de dados de golpe**

Algunas actividades en el campamento permiten recuperar dados de golpe gastados. Estas actividades son acumulables: si consumes una comida caliente, bebes un reconstituyente y duermes bien por la noche, puedes recuperar un total de 3 dados de golpe gastados.
