# Cocinar

¿Que representa?: Preparar una comida mejor que las raciones estándar
¿Necesitas equipo?: Útiles de cocinero

Si sabes cocinar y dispones de los suministros adecuados, puedes preparar una comida para el grupo. Esto requiere el uso de una hoguera y utensilios de cocina. Consume un uso de tus suministros de cocina para intentar una de las siguientes acciones:

- **Preparar raciones:** Cocinas a fuego lento y conservas algunos ingredientes frescos —generalmente carne o grano— para crear 1d4 + 1 raciones de comida básicas nuevas que pueden conservarse.
- **Rendir las raciones**: Transformas unas raciones básicas en una comida sencilla, alimentando a dos personas por cada ración que cocines. Si la preparación tiene éxito, todos los que coman recuperan 1d4 + 1 puntos de golpe (máximo una vez al día).
- **Cocinar una comida caliente:** Preparas una comida caliente para todos, utilizando una ración —o un sustituto de ración— por persona. Si la preparación tiene éxito, todos los que consuman la comida caliente recuperan 1 dado de golpe gastado (máximo una vez al día).

Antes de servir la comida, realiza una prueba de Sabiduría (Supervivencia) para determinar qué tan bien has preparado todo. La comida se echa a perder tras una hora y pierde cualquier propiedad reconstituyente.

Éxito: La comida está bien preparada.

Fallo: Has arruinado la comida y desperdiciado los ingredientes; nadie puede comer lo que has cocinado.
