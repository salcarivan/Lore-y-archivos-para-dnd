# Información Útil

Tipo : General
Requisito nivel: 4
Requisito: INT 13
Bonificador: +1 a INT o SAB

**Conocimiento Enciclopédico.** Cuando realizas una prueba de habilidad de INT para recordar información sobre un tema (Arcana, Historia, Naturaleza, Religión o Sociedad), puedes añadir tu bonificación de competencia aunque no seas competente en esa habilidad. Si ya eres competente, añades el doble de tu bonificación de competencia.

**Dato Crítico.** Una vez por descanso corto, cuando estudias a una criatura durante al menos 1 ronda y superas una prueba de INT (Estudio) CD 15, el DJ debe revelar una de sus vulnerabilidades, resistencias o inmunidades.

**Contexto Inmediato.** Cuando entras en un lugar que no has visitado, puedes realizar una prueba de INT (Historia o Sociedad) CD 12 para recordar datos relevantes sobre ese lugar: su historia, peligros conocidos o habitantes habituales.
