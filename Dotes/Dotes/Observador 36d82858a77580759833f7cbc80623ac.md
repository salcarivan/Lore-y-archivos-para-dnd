# Observador

Tipo : General
Requisito nivel: 4
Requisito: SAB o INT 13
Bonificador: +1 a SAB o INT

**Percepción Aguda.** Tu puntuación de Percepción pasiva aumenta en 5.

**Lector de Situaciones.** Tienes ventaja en las pruebas de SAB (Perspicacia) para determinar si una criatura miente, oculta algo o tiene intenciones hostiles.

**Nada Se Escapa.** Una vez por descanso corto, cuando fallas una prueba de SAB (Percepción) o INT (Investigar), puedes repetirla con ventaja.
