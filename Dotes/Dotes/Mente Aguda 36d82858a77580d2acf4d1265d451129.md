# Mente Aguda

Tipo : General
Requisito nivel: 4
Requisito: INT 13
Bonificador: +1 a INT o SAB

**Procesamiento Rápido.** Puedes realizar la acción de Estudiar como acción bonus una vez por turno en lugar de como acción completa.

**Memoria Fotográfica.** Recuerdas con precisión todo lo que has leído o escuchado en los últimos 30 días. El DJ debe proporcionarte la información exacta de cualquier texto que hayas leído o conversación que hayas escuchado en ese período si la reclamas.

**Deducción Brillante.** Cuando fallas una prueba de INT por 3 o menos, puedes repetirla una vez. Solo puedes usar este rasgo una vez por descanso corto.
