# Sinfonía del Destructor

Requisito de nivel: 7
Activación: Acción adicional
Concentración: No

Entonas una composición ofensiva que intensifica el poder de cada golpe. Mientras esta interpretación está activa y mantienes la concentración, cuando un aliado dentro de 30 pies que pueda oírte impacte con un ataque de arma, puede gastar uno de tus dados de Inspiración Bárdica para añadir el resultado como **daño adicional** del mismo tipo que el arma.

**Simultánea:** Si otra interpretación activa también añade dados de daño a los ataques, ambos se aplican por separado sobre el mismo ataque siempre que el aliado gaste un dado de Inspiración por cada efecto.
