# Interpretaciones Bárdicas

Las Interpretaciones Bárdicas son actuaciones de poder que el bardo mantiene activas durante el combate o la exploración. Cada interpretación tiene un **nivel mínimo de bardo** para ser preparada, que coincide con los hitos en los que puedes mantener más interpretaciones activas simultáneamente. Salvo que se indique lo contrario, iniciar una interpretación cuesta una **acción adicional**.

Cuando mantienes dos o más interpretaciones activas al mismo tiempo, sus efectos se aplican de forma independiente y no se interfieren entre sí salvo que compartan el mismo objetivo o recurso, en cuyo caso solo se aplica el efecto más favorable (no se acumulan bonificaciones del mismo tipo).
