# Secretos Arcanos

Requisito de nivel: 7

Elige un conjuro de **3º círculo o inferior** de cualquier esfera, incluso de una a la que no tengas acceso. Aprendes ese conjuro y puedes lanzarlo una vez sin gastar maná. Debes completar un **descanso largo** antes de volver a lanzarlo de esta forma, aunque también puedes lanzarlo gastando maná normalmente. Este conjuro no cuenta para tu límite de conjuros conocidos. Puedes seleccionar esta invocación varias veces, eligiendo un conjuro diferente cada vez.
