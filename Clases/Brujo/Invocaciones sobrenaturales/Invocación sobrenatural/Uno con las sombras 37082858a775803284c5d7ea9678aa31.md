# Uno con las sombras

Requisito de nivel: 5

Cuando estás en un área de **oscuridad** u **oscuridad total**, puedes usar tu acción para volverte **invisible**. La invisibilidad dura hasta que te muevas, realices un ataque, lances un conjuro o el área deje de estar oscura. No puedes usar esta invocación si llevas fuente de luz alguna.
