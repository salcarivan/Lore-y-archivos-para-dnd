# Tumba de escarcha

Requisito de nivel: 5

Siempre que recibas daño, puedes usar tu reacción para encerrarte instantáneamente en un cristal de hielo. Este hielo tiene una cantidad de puntos de golpe igual a diez veces tu nivel de Brujo y una Clase de Armadura de 10. El hielo absorbe la mayor cantidad posible del daño que activa el efecto. Mientras el cristal de hielo persista, no puedes ser objetivo de ataques y eres inmune a todo daño, pero estás Incapacitado y Restringido.

Al comienzo de tu turno, puedes elegir que este efecto termine, haciendo que el cristal de hielo se derrita tan rápido como apareció.

Puedes usar esta Invocación una vez entre cada descanso corto o largo sin coste alguno. Cuando no te queden usos,

puedes gastar un espacio de conjuro de Magia de Pacto para usarla de nuevo.
