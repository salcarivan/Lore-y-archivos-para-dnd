# Armaduras

La tabla de armaduras enumera las principales armaduras del juego. La tabla incluye el costo y el peso de las armaduras, así como los siguientes detalles:

- **Categoría**. Cada tipo de armadura pertenece a una categoría: ligera, media, pesada o escudo. La categoría determina cuánto tiempo lleva ponerse o quitarse la armadura:
    - Armadura ligera: 1 minuto para ponerse o quitarse la armadura.
    - Armadura media: 5 minutos para ponerse y 1 minuto para quitarse la armadura
    - Armadura pesada: 10 minutos para ponerse y 5 minutos para quitarse la armadura.
    - Escudo: acción [Utilizar](https://www.notion.so/Utilizar-14882858a77580778804e05e1ee686a3?pvs=21) para ponerse o quitarse el escudo
- **Clase de armadura.** La columna de clase de armadura de la tabla te indica cuál es tu CA base cuando llevas un tipo de armadura.
- **Propiedades**. Las propiedades que tiene una armadura se enumeran en la columna Propiedades.
- **Fuerza.** Si la tabla muestra una puntuación de Fuerza en la columna Fuerza para un tipo de armadura, esa armadura reduce la velocidad del usuario en 2 casillas  a menos que el usuario tenga una puntuación de Fuerza igual o superior a la puntuación indicada.

# ENTRENAMIENTO CON ARMADURAS

Cualquiera puede llevar armadura o sostener un escudo, pero solo aquellos con entrenamiento pueden usarlos de manera efectiva, como se explica a continuación. La clase de un personaje y otras características determinan el entrenamiento de armadura del personaje. Un monstruo tiene entrenamiento con cualquier armadura en su bloque de estadísticas

## Armadura ligera, media o pesada

Si llevas armadura ligera, media o pesada y no tienes entrenamiento con ella, tienes [Desventaja](https://www.notion.so/Ventaja-y-desventaja-14882858a77580c8bc9be5a56437acbb?pvs=21) en cualquier [Prueba D20](https://www.notion.so/Pruebas-D20-14882858a77580619f74c37ad6601f51?pvs=21) que involucre FUE o DES, y no puedes lanzar hechizos.

## Escudo

Obtienes el beneficio de la Clase de Armadura de un Escudo solo si tienes entrenamiento con él.
