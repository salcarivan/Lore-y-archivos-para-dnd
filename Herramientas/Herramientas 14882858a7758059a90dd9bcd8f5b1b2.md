# Herramientas

Las herramientas ayudan a los aventureros a realizar tareas complejas que no pueden completar solo con habilidad. Por ejemplo, se usan herramientas para abrir cerraduras, falsificar documentos, cocinar comidas gourmet y forjar armas. Para las tareas que requieren herramientas, el director de juego puede solicitar una prueba de característica que use una herramienta en lugar de una habilidad.

A veces, una herramienta es un único objeto, como un instrumento musical. Otras veces, una herramienta comprende un kit o conjunto de suministros que contiene varios objetos. Al usar una herramienta, debes tener todos los objetos que la componen para poder realizar pruebas de habilidad con ella.

Tus características de trasfondo, clase, herencia, linaje o talento pueden darte competencia con ciertas herramientas. Al igual que con las habilidades, no necesitas ser competente en una herramienta para usarla, pero la competencia con una herramienta te permite sumar tu BC a las pruebas de habilidad que hagas con esa herramienta.

Además, al igual que las habilidades, las herramientas no están vinculadas a puntuaciones de característica específicas. La puntuación de característica asignada a cada prueba de característica que utilice una herramienta depende de lo que intentes lograr. Por ejemplo, al utilizar herramientas de construcción, el DJ podría pedirte que hagas una prueba de FUE (Herramientas de construcción) para clavar clavos en una superficie dura, pero pedirte una prueba de DES (Herramientas de construcción) para utilizar las mismas herramientas para tallar una escultura de madera.

**Habilidades asociadas.** Al igual que las habilidades, las comprobaciones realizadas con herramientas pueden implicar cualquier puntuación de característica. Sin embargo, se incluyen las habilidades más utilizadas con cada herramienta para facilitar su consulta.

## Pruebas de habilidad: ¿Habilidad o herramienta?

Algunas pruebas de habilidad no se pueden realizar sin usar una herramienta. Por ejemplo, no hay forma de abrir una cerradura sin herramientas de ladrón. Un PJ sin herramientas de ladrón puede intentar derribar o abrirse paso a la fuerza a través de una puerta cerrada, pero solo las herramientas de ladrón le permiten abrir la cerradura. El DJ tiene la última palabra sobre si se necesita una herramienta para realizar una tarea.
