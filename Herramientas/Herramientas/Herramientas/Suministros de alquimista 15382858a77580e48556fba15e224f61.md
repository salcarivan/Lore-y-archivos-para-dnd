# Suministros de alquimista

Habilidades asociadas: INT, SAB
Bultos: 2
Precio (po): 50
Tipo: Herramientas de artesano

# Descripción

Viales, quemadores, matraces y otros componentes para preparar medicinas mágicas, pociones, ácidos y brebajes peligrosos o ilegales. El alquimista mezcla ingredientes con precisión química para lograr efectos extraordinarios.

# **Componentes**

Viales, quemadores, matraces, componentes básicos de alquimia, ácidos de muestra y sustancias químicas variadas.
