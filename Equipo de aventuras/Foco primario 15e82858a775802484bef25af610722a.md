# Foco primario

Tipo: Foco de lanzamiento de conjuros
Coste: 5 po
Volumen: 1

Este objeto se puede utilizar como foco de lanzamiento de conjuros para canalizar conjuros primordiales. Algunos ejemplos son un tótem hecho de materiales naturales como plumas o huesos, un bastón de madera tallado a partir de un árbol vivo o una varita de tejo.
