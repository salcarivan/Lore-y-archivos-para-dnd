# Bolsa de componentes

Tipo: Foco de lanzamiento de conjuros
Coste: 25 po
Volumen: 0,2

Una bolsa de componentes es una pequeña bolsa de cinturón de cuero hermética que tiene compartimentos para guardar todos los componentes materiales y otros elementos especiales que necesitas para lanzar tus hechizos, excepto aquellos componentes materiales que tienen un costo de po indicado (como se indica en la descripción de un hechizo).
