# Linterna

Tipo: Generador de luz
Coste: 5 po
Volumen: 1

Esta linterna emite una cantidad [media (+2)](https://www.notion.so/Luz-y-oscuridad-14882858a7758037ba4ee25c04d04d39?pvs=21) de luz durante un máximo de 6 horas. Puedes apagar una linterna encendida con una acción: cada vez que se apague, se restan 15 minutos del
tiempo restante de combustión. Puedes gastar una acción para colocar una linterna con cuidado en el suelo sin apagarla.

- **Combustible:** Esta linterna común requiere aceite como combustible.
- **Con capucha:** Si tu linterna tiene una capucha, puedes cerrarla para reducir la luz emitida a un nivel bajo (+1) o nulo (+0).
- **Caída:** Si la linterna se cae, se tira o se cae por descuido,
se tira un d6:
    - 1-2: La linterna se apaga y pierde d3 horas de combustible
    - 3-4: La linterna se apaga
    - 5-6: La linterna permanece encendida
