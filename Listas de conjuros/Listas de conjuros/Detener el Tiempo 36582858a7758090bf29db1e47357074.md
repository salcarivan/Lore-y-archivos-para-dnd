# Detener el Tiempo

Esfera de conjuro: Realidad
Nivel : 9º círculo
Tiempo de lanzamiento: 1 acción
Rango: Personal
Componentes: V
Duración: Instantáneo 
Tipo duración: Instantáneo (https://app.notion.com/p/Instant-neo-fd7b6c1ffff0428884c14c221d445309?pvs=21)
Ritual: No
Breve descripción: El mundo se congela en un instante perfecto; solo tú sigues moviéndote entre lo inmóvil.

El tiempo se detiene para todas las criaturas excepto tú. Ganas **1d4+1 turnos adicionales** consecutivos antes de que nadie más actúe. Durante estos turnos:

- No puedes afectar directamente a otras criaturas con ataques o conjuros que requieran tiradas de salvación o ataque contra ellas (son intangibles al tiempo detenido).
- Puedes moverte, lanzar conjuros de área o de terreno, usar objetos, equiparte y preparar efectos que se activarán al reanudarse el tiempo.
- Los conjuros de concentración lanzados durante el tiempo detenido no requieren concentración activa hasta que el tiempo se reanude.

Si cualquier efecto creado durante el tiempo detenido afectaría a otra criatura, el tiempo se reanuda inmediatamente.
