# Eco Temporal

Esfera de conjuro: Realidad
Nivel : Truco
Tiempo de lanzamiento: 1 reacción
Rango: Personal
Componentes: S, V
Duración: Instantáneo
Tipo duración: Instantáneo (https://app.notion.com/p/Instant-neo-fd7b6c1ffff0428884c14c221d445309?pvs=21)
Ritual: No
Breve descripción: Repites el pasado inmediato; un momento vuelve a ocurrir, aunque no exactamente igual.

Al inicio de tu turno, antes de realizar cualquier acción, puedes usar tu reacción para **repetir el último truco** que lanzaste (debe ser un truco sin coste de maná). El truco se lanza inmediatamente con los mismos parámetros, pero debes elegir el objetivo de nuevo. Solo puedes usar este efecto una vez por descanso corto.

**Mejora de truco (nivel 17):** Puedes usar este efecto dos veces por descanso corto.
